# Новогодняя ёлка на компьютере "Радио-86РК"

Программка переливающейся новогодней ёлки для "Радио-86РК", написана по мотивам консольного скрипта https://github.com/sergiolepore/ChristBASHTree.

Программа запускается на 4-х конфигурациях: стандартном РК, модифицированном РК-Nova, РК/60-Nova и Апогей.

Для упрощения программы не учитывается ограничение на количество атрибутов контроллера ВГ75, на качество картинки это не влияет.

## Параметры программы

Программа имеет область переменных, которые можно менять из `МОНИТОРа` и, соответственно, будет меняться отображение ёлки.

В скобках значение по умолчанию в hex:

* адрес 0003 (2A) -- код символа, которым рисуется ёлка
* адрес 0004 (24) -- код символа, которым рисуется гирлянда
* адрес 0005 (03) -- смещение вершины ёлки от верхнего края экрана
* адрес 0006 (18) -- размер ёлки
* адрес 0007 (32) -- задержка в мс при переключении цвета ламп гирлянды, чем меньше, тем чаще мерцает гирлянда
* адрес 0008 (23) -- размер (условный) гирлянды
